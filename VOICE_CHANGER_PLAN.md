## 2. Design

- **The engine lives inside BuzzEdit, in its own environment.** seed-vc pins numpy 1.26, transformers 4.46,
  descript-audio-codec, funasr, modelscope — they cannot share BuzzEdit's venv (numpy 2.4, faster-whisper,
  torch 2.11). So `BuzzEdit/engines/seedvc/` holds the vendored seed-vc, its own venv and a small `cli.py`;
  brief S0 adds the CLI and points BuzzEdit at SkinWalker's existing `vendor/seed-vc` + `.venv` (nothing moved
  until S4, so SkinWalker keeps working until BuzzEdit's Voice panel replaces it) and ports `setup.ps1` to
  `scripts/setup_seedvc.ps1`, which builds `engines/seedvc/` on a fresh machine; S4 moves the folders.
  BuzzEdit's backend runs the CLI as a **subprocess** (JSON in, JSON progress lines + WAV out): one app for
  the creator, and the GPL code stays in its own process, never imported into BuzzEdit.
- **Voices library in BuzzEdit**: `data/voices/<name>.wav` + `data/voices/voices.json` (kind woman/child/
  demon/…, consent note, created, duration). API list / upload / **record from the microphone** / rename /
  delete. The Studio reads it through BuzzEdit's API; nothing is duplicated.
- **Conversion is a process effect** of the Audio Suite (`voice_conversion`: voice, preset, Match my pitch
  contour, pitch shift, quality steps) on the process lane: it writes a version WAV, sets `audio_override`,
  Undo pops it; a region = the effect's rack window; Preview renders the selected range; GPU work follows the
  GPU policy (eject other models before, offload after) and refuses to start while a render or production runs.
- **Creature FX become live rack effects** after the conversion: Pitch Shifter, Distortion, Reverb, a
  sub-octave (pitch −12 st mixed in) and the suite's **real** `pyworld` formant shifter — so the FX are
  heard live while the knob moves (SkinWalker's were offline, and its formant was a shelf tilt). The five
  presets map to a voice + conversion settings + an FX rack preset.
- **The Editor tab becomes native BuzzEdit**: drag a range on the A1 (or any audio) lane → right-click
  "Convert voice…" (voice/preset/FX) or "Cut" (BuzzEdit's existing cut); the Voice panel's **Regions** list
  shows every conversion region with its voice and FX (= SkinWalker's manifest, now saved with the project),
  **Apply** runs the pending conversions with progress, each seam crossfaded 15 ms, unmarked audio untouched;
  a failed region keeps the original and is flagged.
- **Convert and Batch**: the Voice panel's **Convert** tab takes the selected clip, a media-pool file or a
  fresh microphone recording, converts it whole, and puts the result in the media pool (+ Download WAV/MP3);
  **Batch** converts a multi-selection of media-pool files with one voice + preset.
- **Speaker spans + voice map** (the production path): `script_align.parse_script` records the speaker label
  of every spoken paragraph; `speaker_spans()` yields `{speaker, start_s, end_s}` on the kept words. A project
  setting `voice_map` `{speaker → voice settings}` converts every span of that speaker after the cut and
  before the mix, with `length_adjust = 1.0` so the cut and the B-roll placement stay valid; the narrator
  (the creator) is never converted. Report: `voice_conversions: [{speaker, voice, spans, seconds}]`.
- **BuzzcafStudio only drives it**: the cast sheet gains `voice: {ref, preset, pitch_shift, f0_condition,
  fx}` per character (an agent proposes it from gender/age/creature: woman → Woman, child → Child, creature →
  Demon/Monster, dead → Ghost; the Projects page lets the creator change it), the production sends
  `voice_map` with the script, the report shows the conversions, and "Open in BuzzEdit → Voice" deep-links.
  Dexter: read "voices", "voice map of project X", "voice conversions in the last production"; safe write "set
  the voice of character X in project Y"; deleting voices is refused. No voice UI in the Studio.

### 2.7 Interfaces for the Voice panel (briefs S2a backend and S2b UI build against these; S1 is done)

**Project data** (project settings, saved with the project): `voice_map` (S1: `{speaker → {voice, preset?, match_pitch, pitch_shift, steps}}`)
and `voice_regions: [{id, start_s, end_s, voice, preset?, params: {match_pitch, pitch_shift, steps, cfg_rate}, fx: [AudioEffect-shaped dicts],
status: "pending"|"applied"|"failed", error?, applied_version?}]` — `start_s/end_s` are **programme seconds** (what the timeline shows);
overlaps are trimmed like SkinWalker's `parse_manifest`.

**Routes** (prefix `/api/audio`, in `routes/audio_voice.py`; S1's routes stay as they are):

| Route | Body → result |
|---|---|
| `GET /{project}/voice/regions` | `{regions}` |
| `PUT /{project}/voice/regions {regions}` | replace, validate (inside the programme, trimmed overlaps), `revision += 1`, `{regions}` |
| `POST /{project}/voice/regions/apply {ids?}` | job: every pending (or listed) region → programme → source pieces (`timeline/program_time.program_to_source`), all converted in ONE new version through the voice-map machinery (`length_adjust` 1.0, 15 ms crossfades), regions marked applied/failed, and each region's `fx` effects added to the A1 rack windowed to the region (programme time) tagged `preset: "voice_region:<id>"`; `{job_id}`; the job result = `{applied: [...], failed: [...], version}` |
| `POST /{project}/voice/regions/undo` | undo the last apply: `processes.undo` + remove the tagged rack effects + regions back to pending; `{regions}` |
| `POST /{project}/voice/convert {source_id?, start_s, end_s, program_range?, voice, preset?, params}` | S1's route, now with `program_range: true` = programme seconds mapped to source pieces; `{job_id}` |
| `POST /{project}/voice/convert_file {media_id? \| path?, voice, preset?, params, name?}` | job: converts a whole media-pool item (or the project source) to a new 48 kHz WAV under the project's `audio/converted/` and registers it as a new media-pool item (the way `routes/projects.py` adds media); result `{media_id, path, seconds}` |
| `POST /{project}/voice/batch {media_ids: [...], voice, preset?, params}` | job over the items (progress per item); result `{items: [{media_id, out_media_id, path} \| {media_id, error}]}` |
| `GET /voice/presets` | S1: name → voice stem, engine overrides, `fx` rack (only existing catalogue ids) |
| `GET /voices`, `POST /voices` (multipart file + name + kind + consent — a browser recording in webm/opus is accepted, ffmpeg converts), `PUT /voices/{name}`, `DELETE /voices/{name}` | S1 |
| `GET /voice/worker`, `POST /voice/worker/stop` | S1 |

`processes.run_process`, `start_job` and `preview_process` gain `ranges: List[Tuple[float, float]] | None` (several source ranges spliced into
ONE version); `routes/audio_process.py` then stops answering 409 for a programme range that spans a cut (L2 checks the signature already).

**UI** (`src/components/VoicePanel.tsx`, `src/components/voice/*`, `src/hooks/voiceApi.ts`): tabs **Convert** (source = selected clip /
media-pool item / microphone recording via MediaRecorder → upload; voice or preset; Match my pitch contour; pitch shift; quality steps; FX summary
from the preset; Convert → new media-pool item + Download WAV/MP3), **Batch** (multi-select media-pool items → one voice + preset → run with
progress), **Regions** (the list of `voice_regions` with per-region voice/preset/params/FX, add from the timeline's `audioSelection` or from the
band's context menu "Convert voice…", Apply pending → job progress, Undo last apply, status badges), **Voices** (list, record 5–60 s with a
level meter, upload, rename, delete, kind, consent note; the Worker's status + Stop). The panel is registered in the dock like the Audio panel.
