## 2. Design

### Clips (BuzzEdit = brief E, Studio = brief F)

1. **World line = look only.** Studio `CAST_PROMPT`: the world line describes only what is in every frame (season, time of day, weather, light, palette, vegetation or architecture textures) — no animals or creatures, no people, no named parks, reserves, cities or brands. `visual_world()` sanitises an existing line (creature nouns and "tiger reserve/sanctuary/national park" → "protected forest" etc.) on load and on append. `_with_continuity` never adds a creature word the beat's own prompt lacks. `lint_prompt()` is the last guard on every outgoing prompt.
2. **Prompt-drift report (BuzzEdit).** After generation: any content noun present in > 60 % of prompts is reported (`prompt_drift: {"tiger": 0.91}`) with a warning naming the world/look line as the usual cause.
3. **Near match on the beat's own words.** Tokens shared by ≥ 50 % of this run's prompts (world, cast looks, genre look) are boilerplate and excluded from the Jaccard; the threshold applies to the remainder (≥ 6 tokens).
4. **One asset, one beat.** `generate_assets` tracks assets already used in this programme; a near match already used is skipped (the next candidate, else generate). Identical prompts at different beats keep their per-beat seeds and are generated separately.
5. **Consecutive shots differ.** `VARIATION_SYSTEM` asks for N *different subjects or moments* of the topic (different object, place, action or detail), never the same subject from another angle; no deterministic angle-suffix fallback (fewer slices instead). After planning, `adjacent_similarity` drops the later of two consecutive cutaways whose beat-specific tokens overlap ≥ 60 %.
6. **Clips ≥ 5 s.** `MIN_VIDEO_FRAMES` = 81 (5 s at 16 fps); a `broll_video` beat's planned length is at least 5 s (cap 8); placement never cuts a video cutaway under 5 s — a slot that cannot hold 5 s makes the beat a still. `_video_length_for` adds its 0.3 s slack as before.
7. **No still inside a clip.** Keep the 2026-10-08 compiler fix; add a render check in `presentation/verify.py`: a generated-clip segment whose consecutive frames are identical for ≥ 0.5 s is reported (`frozen_clip_frames`).
8. **Toggle: `clip_generation_mode` = `classic` | `hq`** (BuzzEdit app setting, `GET/PUT /api/settings/clip_generation`; Studio setting of the same name pushed before production, with a select on the Studio Projects page). `classic` → `zimage_wan22_i2v.json`, 832×480, 16 fps. `hq` → new `zimage_wan22_i2v_hq16.json` = the HQ graph without RIFE (`v_create.images` ← `u_scale`, fps 16), 1024×576, delivered at 1920×1080, fallback classic. `MAX_VIDEO_GEN_PIXELS` follows the mode. Both run at 16 fps native (the creator's 16–20 fps).

### Sound (BuzzEdit = brief G, Studio cues = brief F)

9. **Library index** `presentation/sfx_library.py`: roots = `data/sfx` + `sfx_library_dirs` (default the creator's Effects folder); recursive; per file path, duration, tags from folder and file-name tokens (camelCase/space split, freesound names), category (music = loose root files > 60 s with " - Artist" names; effect otherwise), licence `own` for the creator's folder (declared by the creator 2026-10-09), cached in `data/sfx_index.json` by path + mtime. Synonym map (footsteps ← walk/walking/steps/boots; running ← run/sprint/chase; shout ← yell/scream; thunder ← storm; rain; wind ← howl; door ← creak/knock/slam/bang; phone ← ring; car ← jeep/engine/vehicle; bike ← motorcycle; train; bell ← temple; dog ← bark; birds; crickets ← insects/night; owl; bats; heartbeat; knife; gunshot; fall ← thud; glass; whisper; laugh; weep ← cry/sob; water ← drip/river; fire ← crackle; crowd ← chatter/gossip/kids). `resolve_effect(text)` → best file by tag score, else Stable Audio generation (cached, noise-guarded), else none.
10. **Cues.** `SfxCue` gains `text`, `path`, `kind` (`accent` | `bed`), `duration_s`, `duck`, fades; `LoopCue` gains `path`. Every placed effect file is loudness-normalised once (`loudnorm` to −18 LUFS accents, −24 beds) into `data/sfx_cache/`. Gains: accent 0.35 × `sfx_volume`, subtle 0.18, bed 0.12; `duck` 0.35 accents, 0.6 beds — the voice is always on top; hard cap at `sfx_volume`; ≤ 8 diegetic one-shots per minute, none within 1.2 s of another one-shot.
11. **Planner** `presentation/sound_design.py`: one model pass per 60-line window with the words (timestamps) and the on-screen beats: `{"cues": [{"anchor": "exact words", "effect": "footsteps running on wet leaves", "kind": "accent|bed", "level": "subtle|normal", "seconds": 3}]}`; anchors resolve to times like script directives; validated (effect ≤ 8 words, 0.5–20 s, beds up to the paragraph); diegetic only, never music. Keyword fallback from beat prompts (walking, running, door, car, rain, thunder) when the model is unavailable. Director runs it before `_apply_sound`; `plan_sound` accepts `diegetic` cues; `apply_sound` places them via `resolve_effect`. Script `[sfx: footsteps on gravel | kind=accent | level=subtle | seconds=3]` directives feed the same path (a known tag keeps today's behaviour).
12. **Studio cues.** `visual_windows` asks each window for `sounds` (anchor, effect, kind, level, seconds) and `buzzedit_script` writes them as the directives above, so the Studio's planners decide where and how loud.
13. **Report**: `diegetic_placed`, `diegetic_sources` (library/generated/none), `diegetic_unresolved`, shown with the production summary.
